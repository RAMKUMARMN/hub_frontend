# Discover Components

Analyze reusable UI elements.

## Focus Areas

- Prop Type Specifications
- UI State Changes
- Layout Hooks

## Goals

- Map presentation building blocks
- Verify isolated interface layouts

## Output

Return:
- Component schema layout sheets
- Prop integration specs

## Workflow

1. Parse design component libraries
2. Map parameter signatures
3. Isolate sub-component maps
4. Return findings
