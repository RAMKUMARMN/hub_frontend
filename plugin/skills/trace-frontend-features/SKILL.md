# Trace Frontend Features

Analyze frontend feature implementations.

## Focus Areas

- Pages
- Components
- State Management
- Services
- UI Flows

## Goals

- Locate feature ownership
- Trace UI implementation
- Identify related assets

## Output

Return:
- Matching files
- Related components
- Feature locations

## Workflow

1. Receive feature name
2. Search frontend source tree
3. Locate matching files
4. Return findings
